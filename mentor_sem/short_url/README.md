# Проект Todo API

## Описание
В данной папке содержатся все, что я успел написать для приложения сохранения укороченный ссылок. Я успел раскатить Postgress, PgAdmin и само FastApi прилодение с очень уркзанным функционалом. При создании базы создается таблица с первой тестовой строкой каак требуется по заданию, но база не интегрирована в функционал FastApi (На данный момент!)

## Основные возможности

1. **Создание короткой ссылки:**

## Установка и запуск

### Шаг 1: Клонирование репозитория

Склонируйте репозиторий проекта:
```bash
git clone <ссылка на репозиторий>
cd mentor_sem/short_url
```

### Шаг 2: Запуск docker-compose

Запустите команду 
```bash
docker-compose up -d 
```
спустя всего пару минут контейнеры соберутся и все будет готово для работы;)


### Шаг 3: Запуск приложения

В данном приложении есть сразу несколько модулей:
   - **PgAdmin будет доступен по адресу: http://localhost:6060/browser/
   - **FastApi с удобной ui-кой будет доступен по адресу: http://localhost:8000/docs#/

## Технологии
- **FastAPI**: Фреймворк для создания API.
- **Uvicorn**: ASGI сервер для запуска приложения.
