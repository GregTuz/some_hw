## Основные возможности

1. **Создание новой задачи:**
   - Эндпоинт: `POST /items`
   - Принимает данные задачи (название, описание, статус выполнения) и добавляет её в базу данных. Пример: Ultratask-228;A real one;False

2. **Получение всех задач:**
   - Эндпоинт: `GET /items`
   - Возвращает список всех задач.

3. **Получение задачи по ID:**
   - Эндпоинт: `GET /items/{item_id}`
   - Возвращает задачу по её уникальному идентификатору. Пример: Ultratask-228

4. **Обновление существующей задачи:**
   - Эндпоинт: `PUT /items/{item_id}`
   - Позволяет изменить информацию о задаче. Пример: Ultratask-69;A fake one;False

5. **Удаление задачи:**
   - Эндпоинт: `DELETE /items/{item_id}`
   - Удаляет задачу по её уникальному идентификатору. Пример: Ultratask-69

## Установка и запуск

### Шаг 1: Клонирование репозитория

Склонируйте репозиторий проекта:
```bash
git clone <ссылка на репозиторий>
cd mentor_sem/todo_app
```

### Шаг 2: Запуск docker-compose

Запустите команду 
```bash
docker-compose up -d 
```
спустя всего пару минут контейнеры соберутся и все будет готово для работы;)


### Шаг 3: Запуск приложения

В данном приложении есть сразу несколько модулей:
   - **PgAdmin будет доступен по адресу: http://localhost:6060/browser/
   - **Grafana будет доступна по адресу: http://localhost:3000/
   - **FastApi с удобной ui-кой будет доступен по адресу: http://localhost:8000/docs#/

## Технологии
- **FastAPI**: Фреймворк для создания API.
- **Uvicorn**: ASGI сервер для запуска приложения.
